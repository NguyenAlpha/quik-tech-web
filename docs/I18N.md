# I18N — Đa Ngôn Ngữ

## 1. Tổng quan

App hỗ trợ 2 ngôn ngữ: **Tiếng Anh (en)** và **Tiếng Việt (vi)**.

Cơ chế hoạt động:
- Tất cả text hiển thị đều lấy từ object `translations` trong `lib/translations.ts`
- User toggle ngôn ngữ qua `LanguageSwitcher` ở header
- Preference lưu vào `localStorage("language-preference")`
- Không có URL-based routing (không có `/en/`, `/vi/` trong URL)

---

## 2. Cấu trúc translations.ts

File `lib/translations.ts` export một object `translations` chứa 2 key con: `en` và `vi`.
Cả hai phải có **cùng cấu trúc key** — nếu thiếu key ở một ngôn ngữ sẽ bị lỗi TypeScript.

```ts
// lib/translations.ts

export const translations = {
  en: {
    common: {
      save: 'Save',
      cancel: 'Cancel',
      delete: 'Delete',
      edit: 'Edit',
      loading: 'Loading...',
      logout: 'Logout',
    },
    nav: {
      dashboard: 'Dashboard',
      products: 'Products',
      // ...
    },
    products: {
      title: 'Products',
      subtitle: 'Manage your product catalog',
      addNewProduct: 'Add Product',
      searchPlaceholder: 'Search products...',
      // ...
    },
    // ... các section khác
  },
  vi: {
    common: {
      save: 'Lưu',
      cancel: 'Hủy',
      delete: 'Xóa',
      edit: 'Chỉnh sửa',
      loading: 'Đang tải...',
      logout: 'Đăng xuất',
    },
    // ... phải có đủ key như en
  }
}

export type Translations = typeof translations.en
```

## 3. LanguageContext (lib/language-context.tsx)

```ts
interface LanguageContextValue {
  language: 'en' | 'vi'           // Ngôn ngữ hiện tại
  setLanguage: (lang: 'en' | 'vi') => void
  t: Translations                  // Object dịch của ngôn ngữ hiện tại
}
```

`t` là shorthand — thay vì `translations[language].products.title`
chỉ cần viết `t.products.title`.

---

## 4. Hook useLanguage()

```tsx
import { useLanguage } from '@/lib/language-context'

export function ProductsPage() {
  const { t } = useLanguage()

  return (
    <div>
      <h1>{t.products.title}</h1>
      <p>{t.products.subtitle}</p>
      <button>{t.common.save}</button>
    </div>
  )
}
```

Pattern phổ biến trong các page — destructure trước để viết ngắn hơn:

```tsx
const { t } = useLanguage()
const tp = t.products      // Alias cho section dùng nhiều trong page
const tc = t.common

<h1>{tp.title}</h1>
<button>{tc.save}</button>
```

## 5. Cách thêm key mới

**Ví dụ:** Thêm key `editProduct` vào section `products`.

### Bước 1 — Thêm vào `en`

```ts
// lib/translations.ts
en: {
  products: {
    title: 'Products',
    // ... các key hiện có ...
    editProduct: 'Edit Product',   // ← thêm vào đây
  }
}
```

### Bước 2 — Thêm key tương ứng vào `vi`

```ts
vi: {
  products: {
    title: 'Sản phẩm',
    // ... các key hiện có ...
    editProduct: 'Chỉnh sửa sản phẩm',  // ← thêm vào đây
  }
}
```

### Bước 3 — Dùng trong component

```tsx
const { t } = useLanguage()
<button>{t.products.editProduct}</button>
```

> TypeScript sẽ báo lỗi ngay nếu bạn thêm key vào `en` mà quên thêm vào `vi`
> — vì type `Translations` được infer từ `typeof translations.en`.

## 6. Cách thêm section mới

**Ví dụ:** Thêm section `reports` cho trang báo cáo.

```ts
// lib/translations.ts
en: {
  // ... sections hiện có ...
  reports: {
    title: 'Reports',
    subtitle: 'View sales and inventory reports',
    dateRange: 'Date Range',
    export: 'Export',
    noData: 'No data for selected period',
  }
},
vi: {
  // ... sections hiện có ...
  reports: {
    title: 'Báo cáo',
    subtitle: 'Xem báo cáo doanh thu và tồn kho',
    dateRange: 'Khoảng thời gian',
    export: 'Xuất file',
    noData: 'Không có dữ liệu trong khoảng thời gian này',
  }
}
```

## 7. Cấu trúc sections hiện tại

| Section | Dùng ở |
|:---|:---|
| `common` | Dùng chung: save, cancel, delete, edit, loading, logout... |
| `nav` | Tên menu trong sidebar |
| `header` | DashboardHeader: search, notifications |
| `dashboard` | Trang / (Dashboard) |
| `products` | Trang /products và modal |
| `suppliers` | Trang /suppliers và modal |
| `purchaseOrders` | Trang /purchase-orders và modal |
| `orders` | Trang /orders |
| `customers` | Trang /customers |
| `inventory` | Trang /inventory |
| `payments` | Trang /payments |
| `settings` | Trang /settings |

## 8. LanguageSwitcher Component

```tsx
// components/language-switcher.tsx
// Hiển thị dropdown "EN / VI" trong header

<LanguageSwitcher />
```

Khi user chọn ngôn ngữ:
1. `setLanguage('vi')` được gọi
2. `localStorage.setItem('language-preference', 'vi')`
3. `t` được cập nhật → toàn bộ UI re-render với ngôn ngữ mới
4. Lần sau mở app, preference được đọc lại từ localStorage
